### 🚀 What does this do?
This is the companion extension that bridges your Google Chrome browser with the **[Pin Sniper Desktop App](https://github.com/goldydrop/Pin-Sniper)**. It quietly extracts raw target URLs and media grids from your active tab and routes them directly to your desktop client for high-speed processing.
